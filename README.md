# LifeTask

Личный планировщик: задачи по сферам жизни, календарь, Telegram-инбокс, разборы с Claude, аналитика.

- **Ввод дешевле задачи.** Пишешь или наговариваешь боту как получится. Разбор по правилам (или Claude, если есть ключ) превращает текст в карточку с кнопками.
- **Строгая логика, свободное оформление.** Ядро задачи типизировано (статус, даты, матрица «важно/срочно», оценка, связи), содержимое — свободные блоки.
- **ИИ меняет данные только планом:** превью → подтверждение → атомарное применение.

## Состав

| | |
|---|---|
| `cmd/lifeplan` | сервер: API, веб, Telegram-бот, брифы, повторы, синк с Google |
| `cmd/plan` | CLI для вечерних и недельных разборов с Claude Code |
| `internal/web/static` | веб без сборки: день, неделя, доска, входящие, дневник, заметки, аналитика, граф; офлайн-очередь |
| `docs/DESIGN.md` | архитектура и модель данных |
| `docs/PLAN-OPS.md` | формат плана изменений |
| `docs/DEPLOY.md` | развёртывание на VPS, домен, Google |

## Разработка

```bash
make db-up     # локальный Postgres на порту 5434 (Unix-сокет)
make test      # gofmt, vet, интеграционные тесты
make run       # сервер на сокете tmp/lifeplan.sock
bin/plan day today
```
